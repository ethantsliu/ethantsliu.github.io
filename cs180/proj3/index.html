Fun with Flow Models

I first used a pretrained flow model to edit images, then trained my own models on MNIST. The idea is simple: start with noise and learn how to move toward an image.

I used my building and ceramic cactus photos from Project 0, a web photo of the Taj Mahal, and two drawings. Both parts ran on a Colab T4.

Part A: Exploring the Power of Flow Models

I used PixNerd to generate 512×512 images. Throughout this part, time runs from noise at t = 0 to a clean image at t = 1.

1.1 Constructing Noisy Training Inputs

I center-cropped my building photo to 512×512, normalized it to [−1, 1], and reused one Gaussian noise tensor at all three times.

xt = (1 − t)ε + tx1,   ε ∼ N(0, I)

1.2 Classical Denoising

I first divided each noisy input by t to restore its amplitude, then applied Gaussian blur. I tried σ = 1, 2, 4, 8, and 16 and chose the lowest pixel MSE for each input. Blur reduces noise, but also removes the building’s details.

1.3 One-Step Denoising

I used the prompt “a high quality photo” and extrapolated from one velocity prediction:

x̂1 = xt + (1 − t)vθ(xt, t, c)

The building is much blurrier at t = 0.25, whereas larger starting times preserve more of the original.

1.4 Visualizing Velocity

Since we know the clean image and sampled noise, the ground-truth velocity is x1 − ε. I compared its update with the predicted update and computed the per-pixel RGB RMS error before display scaling. All updates share one symmetric RGB scale, with zero at gray; all error maps share the same linear limits.

1.5 Iterative Denoising with Euler Sampling

I recomputed velocity after each Euler update, using step size 0.02. Starting at t = 0.50 takes 25 updates. The sampler also passed the constant-velocity checks, including a shortened final step.

xt+h = xt + hvθ(xt, t, c)

For this image, one-step denoising has slightly lower pixel error than Euler. Iterative sampling also changes some fine details.

1.6 Generating Images from Noise

I sampled five images from Gaussian noise with “a high quality photo,” 50 Euler steps, and seeds 180–184. The generic prompt mostly produces portraits; some faces are distorted.

2.1 Classifier-Free Guidance

I combined the conditional and empty-prompt velocities with w = 7, using the same initial noises as above. The faces are sharper and more consistent, though the generic prompt still produces portraits.

vcfg = vc + w(vc − vu)

3.1 Image-to-Image Editing

I interpolated each image with noise, then sampled with CFG and “a high quality photo.” I reused the same noise throughout each sweep. The starting times are 0.02, 0.04, 0.06, 0.10, 0.14, 0.25, and 0.50.

Smaller starting times leave the model more room to change the image. At larger times, the Campanile and building return closer to their original appearance.

Web Image and Drawings

I repeated the same sweep on the Taj Mahal and my flower and house drawings. The Taj Mahal becomes recognizable as the starting time increases. My outline drawings mostly disappear at low times; at 0.25 and 0.50, their outlines return without becoming realistic.

3.2 Text-Guided Image Editing

I kept the same inputs, noise, starting times, and CFG weight, but changed the text prompts. In the middle of each sweep, the new subject shares some of the original image’s structure.

3.3 Visual Anagrams

I averaged the upright CFG velocity with the rotated-back velocity of the image turned 180°. The old man/campfire pair reads more clearly; the village/horse pair still shares visible horse features in the upright view.

3.4 Hybrid Images

As in Project 2, I combined low and high frequencies. Here, I used the low frequencies of one CFG velocity and high frequencies of another, with Gaussian kernel size 265 and σ = 16.

v = lowpass(va) + vb − lowpass(vb)

The hybrids are pretty subtle: the waterfall and forest read more clearly than the intended skull and cat. These runs do not produce a strong change at a distance.

Part B: Flow Matching from Scratch

I trained on the 60,000 MNIST training images and used held-out test digits for denoising displays. Pixels stay in [0, 1], and new Gaussian noise is drawn for every training batch.

1.1 Implementing the UNet

I used convolution, batch normalization, and GELU blocks, with two downsampling stages and channel-wise skip connections. Average pooling compresses 7x7 features to 1x1, which is then expanded by transposed convolutions.

28×28 → 14×14 → 7×7 → 1×1 → 7×7 → 14×14 → 28×28

1.2 Noising MNIST

I added σ ε to the same test digit, reusing ε across σ = 0, 0.2, 0.4, 0.5, 0.6, 0.8, and 1.

1.2.1 Training a Denoiser

I first trained a D = 128 UNet for five epochs, using batch size 256, Adam with learning rate 10−4, and σ = 0.5. The target is the clean digit, with mean squared error loss. By epoch 5, the reconstructions are cleaner, while retaining the different handwritten shapes.

1.2.2 Out-of-Distribution Testing

I tested the trained denoiser on the same digit across all seven noise levels. The 7 stays recognizable at moderate noise, whereas σ = 0.8 and 1.0 leave more distorted strokes.

1.2.3 Denoising Pure Noise

I trained a fresh D = 128 UNet with the same settings, but used independent Gaussian noise as input. The outputs look like the same blurry oval with overlapping strokes, rather than different digits.

The idea is simple: the input noise tells the model nothing about its target. Under MSE, the best prediction is the conditional mean, which here is the average training image.

D*(ε) = E[x | ε] = E[x]

2.1–2.2 Time-Conditioned Flow Matching

I sampled a separate time for each image and trained the UNet to predict x1 − x0 from xt = (1 − t)x0 + tx1. Two fully connected blocks embed time and multiply the unflattened features and first upsampling output.

I used D = 64, batch size 64, Adam starting at 0.01, and 10 epochs. The exponential scheduler multiplies the learning rate by 0.11/10 after each epoch.

2.3 Sampling from the Time-Conditioned UNet

I sampled 40 images using 50 Euler steps and the same initial noises at epochs 1, 5, and 10. Early samples contain broken strokes; by epoch 10, many have recognizable digit shapes, though some remain ambiguous.

2.4–2.5 Class-Conditioned Flow Matching

I added two class-embedding blocks using one-hot labels, dropping the class vector to zero for 10% of training examples. At each conditioning point, class features multiply the image features and time features are added. I kept D = 64, batch size 64, Adam starting at 0.01, and the same 10-epoch scheduler.

2.6 Class-Conditioned Sampling

I generated four instances of each digit with 300 Euler steps and guidance scale γ = 5. The columns are digits 0–9. Class conditioning already gives recognizable digits at epoch 1; later samples have more complete strokes.

vcfg = vu + γ(vc − vu)

Note that this guidance convention differs from Part A’s vc + w(vc − vu).

Removing the Learning-Rate Scheduler

I trained an independent model for 10 epochs with constant learning rate 0.001 instead of starting at 0.01 and decaying. I reset the seed and kept the data order, architecture, dropout, and sampling noise the same.

The smaller constant rate avoids the larger early updates. Its final grid has similarly readable digits, with some different stroke shapes, so the simpler setup preserves comparable visual quality in these samples.
